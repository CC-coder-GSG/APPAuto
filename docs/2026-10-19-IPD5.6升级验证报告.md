## 首次验证发现的问题及修复状态

1. **平台提 Bug 必填日期：已修复，待部署。** 已补齐截止日期的界面、请求模型和转发字段。真实通过平台 API 创建临时 Bug 33514，回读确认日期正确，并完成删除。
2. **任务创建日期校验：已修复，待部署。** 已补齐任务看板前端必填和有效性检查，后端在创建前校验完整起止日期及顺序；不替用户擅自指定日程。
3. **大项目版本同步耗时。** 对项目 134 的平台同步请求在 120 秒后超时。请求跟踪显示代码逐一查询历史执行详情以寻找 `products`，而当前实例 v2 执行详情没有返回预期的关联产品集合。这条产品解析路径需要调整。小项目同步成功不能覆盖此问题。
4. **工时超时核对和删除确认：已修复，待部署。** 已增加工时专用写超时、提交后只读核对、明确的结果未知保护，以及完整的 IPD 5.6 删除确认路径。真实复验通过新增、编辑和最后一条删除，状态保护服务确认任务仍保持操作前状态。后续临时工时 209198 已清理；网络故障时仍可能暂时无法确定结果，此时会停止自动重复新增。
5. **权限限制。** 项目级构建列表返回 `403 Access not allowed`；执行级构建列表可用。任务和构建删除的 API 返回 403，同账号网页也明确返回 `denyType=nopriv`，所以本账号无法完成这些对象的删除。不能把权限拒绝判成删除功能通过。
6. **当前本地旧绑定不可直接使用。** 验证开始时，本地数据库 4 个旧绑定均无法用当前工作区配置解密，旧 Token 访问 v2 也返回 403。新提供账号在独立副本中的绑定和认证成功；未擅自覆盖本地原绑定。部署时需要核对实际加密配置或重新绑定。
